# Proyecto Titanic - Análisis con Pandas

## Descripción
Análisis exploratorio del conjunto de datos del titanic usando Python y Pandas,
desarrollado como proyecto de la materia Programación II -- Ciencia de Datos.

## Objetivos
-Cargar y explorar los datos del Titanic
-Analizar variables y estadísticas descriptivas
-Responder preguntas sobre supervivencia
-Generar gráficos que permitan exponer los análisis y descripciones a realizar

## Estructura del proyecto
titanic-pandas-proyecto/
├── data/           # Instrucciones para descarga de datos
├── notebooks/      # Notebook principal del análisis
├── src/            # Scripts de Python
├── outputs/        # Tablas y gráficos
└── docs/           # Informe final

## Cómo ejecutar el proyecto
1. Clonar el repositorio
2. Descarga los datos siguiendo las instrucciones en `data/README.md`
3. Instala las librerías necesarias:
```bash
pip install pandas matplotlib seaborn
```
4. Abre `notebooks/proyecto_titanic.ipynb` en VS Code o Jupyter

## Dataset
Datos del concurso Titanic de Kaggle:
https://www.kaggle.com/competitions/titanic
