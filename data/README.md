# Datos del Titanic

Los archivos de datos NO están incluidos en este repositorio.

## Instrucciones de descarga

1. Ir a: https://www.kaggle.com/competitions/titanic/data
2. Iniciar sesión en Kaggle
3. Descargar los siguientes archivos:
   - train.csv
   - test.csv
4. Colocarlos en esta carpeta (data/)
